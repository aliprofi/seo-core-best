## 🎯 Главная цель плагина

Большинство современных SEO-плагинов (Rank Math, Yoast SEO, All in One SEO) со временем превратились в тяжелые, перегруженные системы: десятки тяжелых фоновых скриптов, сторонние запросы к серверам аналитики, навязчивые баннеры платных Pro-версий и замедление работы сайта.

**SEO Core Best** решает эту проблему кардинально:
* **Вес плагина — всего ~100 КБ** (в 400 раз легче Rank Math).
* **0 внешних запросов** к сторонним серверам и телеметрии.
* **100% совместимость** со всеми мета-полями и переменными Rank Math — переход происходит бесшовно, без потери данных.
* **Встроенный автономный AI-ассистент** (прямой доступ к API DeepSeek и Mistral AI без посредников и ежемесячных подписок).

## 🛠️ Основные модули и функционал

### 1. 🏷️ Заголовки, Мета-теги и Шаблоны
* Настройка шаблонов для Главной, Статей, Страниц, Рубрик, Меток, Авторов, Поиска, Ошибки 404 и любых произвольных типов записей (Custom Post Types).
* **Поддержка переменных Rank Math:**
  * `%title%`, `%sitename%`, `%sep%`, `%org_name%`, `%sitedesc%`, `%excerpt%`, `%url%`
  * `%category%`, `%categories%`, `%tag%`, `%tags%`, `%term%`, `%term_description%`
  * `%currentyear%`, `%currentmonth%`, `%currentday%`, `%currentdate%`, `%currentdate(format)%`
  * `%date%`, `%modified%`, `%date(Y)%`, `%modified(d.m.Y)%`
  * Динамические шорткоды: `[currentyear]`, `[upcomingmonth]`, `[currentmonth]`
  * `%author%`, `%name%`, `%focuskw%`, `%page%`

### 2. 🌐 Соцсети, OpenGraph и Twitter Cards
* Генерация валидных тегов `og:title`, `og:description`, `og:image`, `og:url`, `og:site_name`, `og:type` для красивых карточек-превью в **Telegram, WhatsApp, ВКонтакте**.
* Карточки **Twitter / X Cards** (`summary_large_image` или `summary`) с привязкой `@username`.
* **Изображение по умолчанию (Default Share Image):** выбор картинки через встроенную медиабиблиотеку WordPress (`wp.media`) для страниц и архивов без миниатюры.
* **Связка с Schema.org:** ссылки на сообщества (Telegram, VK, YouTube, Twitter, Facebook) автоматически транслируются в блок `sameAs` микроразметки Organization для Google Knowledge Graph.

### 3. 🔀 301 Редиректы и Удаление `/category/`
* Мощный и компактный движок перенаправлений с автоопределением циклов (Redirect Loops).
* Быстрое создание редиректа прямо из верхней панели сайта (Admin Bar) на любой 404 странице без перехода в панель управления.
* **Удаление `/category/` из ссылок рубрик (Strip Category Base):** формирование чистых адресов вида `site.ru/rubrika/` с сохранением древовидной структуры, автоматическим 301-редиректом со старых URL и автосбросом правил ЧПУ.

### 4. 🔍 Продвинутый Монитор 404 Ошибок
* Фиксация каждого битого обращения с точным определением реального IP (с учетом Cloudflare CF-Connecting-IP и X-Forwarded-For).
* Автоопределение ботов и поисковиков: Googlebot, YandexBot, Bingbot, AhrefsBot, мобильных и десктопных браузеров.
* Определение источника (Referer) с цветовыми бейджами «Внутренняя» / «Внешняя ссылка».
* Классификация типа запроса (Страница, Картинка, CSS/JS ассет, Файл) и кнопка мгновенного создания 301-редиректа в 1 клик.
* Адаптивная таблица с естественным переносом длинных ссылок по слэшам.

### 5. 🗺️ Чистая XML Карта Сайта (Sitemap)
* Автоматическая генерация индексного файла `/sitemap_index.xml` и карт для каждого типа записей (`/post-sitemap.xml`, `/page-sitemap.xml`, `/category-sitemap.xml`).
* Поддержка изображений (Google Image Sitemap) внутри каждого URL.
* Поддержка разбивки на страницы (Sitemap Pagination) для крупных проектов.

### 6. 🚀 Мгновенная Индексация (Google Indexing API & IndexNow)
* **Google Indexing API:** прямая отправка URL в Google через встроенную криптографию OpenSSL (RS256 JWT) без установки тяжелых библиотек Google Client SDK.
* **IndexNow API:** мгновенное уведомление поисковых систем **Яндекс** и **Bing** о публикации или обновлении статьи.
* Автоматическая отправка при сохранении/обновлении записей выбранных типов.
* Вкладка с историей отправок, логом кодов ответов поисковиков и кнопкой ручной отправки любого URL.

### 7. 🎯 Локальный On-Page SEO Анализатор
* Полная проверка страницы по 18+ ключевым On-Page SEO факторам (Title, Description, H1-H3, плотность текста, Robots, Canonical, HTTPS, скорость генерации, вес HTML, OpenGraph, Schema.org, сырые шорткоды).
* **Работает 100% автономно** прямо на вашем сервере, обходя серверный кэш страниц и не обращаясь к внешним API.
* Цветной круговой рейтинг качества (SEO Score 0–100) и фильтрация проблем в 1 клик.
* Вызов анализа любой страницы сайта прямо из Admin Bar в верхней панели.

### 8. 🤖 AI Ассистент (DeepSeek & Mistral AI) и Image SEO
* **Авто-Alt для картинок на лету:** автоматическое заполнение отсутствующих тегов `alt` и `title` по настраиваемому шаблону (`%title%`, `%filename%`, `%count%`) без нагрузки на базу данных и без затрат токенов.
* **AI исправление в 1 клик прямо в Анализаторе:**
  * Сокращение и оптимизация слишком длинных или коротких Meta Description через нейросеть.
  * Генерация кликабельных высоко-CTR заголовков SEO Title.
  * Умное создание смысловых Alt-тегов для картинок статьи с анализом контекста окружающего текста.
* **AI кнопки в метабоксе записи:** генерация мета-данных и пакетное заполнение Alt для всех иллюстраций статьи перед публикацией.

## 💻 Установка

1. Скачайте репозиторий в папку плагинов WordPress:
   ```bash
   cd wp-content/plugins/
   git clone https://github.com/aliprofi/seo-core-best.git
   ```
2. Активируйте плагин **SEO Core Best** в панели администратора WordPress: **Плагины &rarr; Установленные**.
3. Если ранее использовался Rank Math, перейдите во вкладку **«📦 Миграция из Rank Math»** и нажмите кнопку **«Импортировать настройки из базы данных»** — все ваши мета-поля, шаблоны и редиректы подхватятся моментально!
